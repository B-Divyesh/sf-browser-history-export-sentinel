Copy, export, and verify

How Sentinel verifies an export

Keep the verification report with your export. Run the check again after moving the folder.

  1. 01

    Find profiles

    Find Firefox and Chromium-family profiles in standard Windows, macOS, and Linux locations.

    sentinel scan
  2. 02

    Copy before reading

    Copy the history database and its SQLite side files to a private temporary folder.

    History → temporary copy
  3. 03

    Verify exported files

    Check each file hash, the record count, and the date range against the report.

    sentinel verify ./history-archive

Clear boundaries

What Sentinel does not do

  • ×

    It does not archive web pages. It exports history records only.

  • ×

    It does not read passwords or cookies. Encrypted browser data remains out of scope.

  • ×

    It does not hide errors. Permission problems, unsupported database formats, and changing files stop with a specific code and next step.
