Plain-language policy

Privacy

Effective 28 August 2026

Sentinel processes browser history on your computer. The CLI has no network client, account system, telemetry, advertising, or analytics.

What the CLI reads

Sentinel copies the selected history database and present SQLite side files to a private temporary folder. It reads URLs, titles, visit times, and visit counts from that copy. The temporary copy is deleted when the command finishes.

What it writes

Sentinel writes JSON, CSV, and a verification report to your chosen output folder. The report omits the source profile’s full path. These files are sensitive. Protect or delete them as you would the original history.

This website

This site sets no cookies. It uses no analytics, tracking pixels, third-party fonts, or third-party scripts. A service worker caches public pages for offline reading. The demo stores only its selected state under a demo: key. Reset demo removes it.

Contact and changes

File questions in the public project repository (opens GitHub). The project has no account service that can retrieve your exports.
