Plain-language policy

Privacy

Effective 28 August 2026

History Export Sentinel is designed so your browser history does not need to leave your computer. The command-line tool has no network client, account system, telemetry, advertising, or analytics.

What the CLI reads

When you run an export, Sentinel copies the selected browser history SQLite database and its present sidecars to a temporary local directory. It reads the copy to export URLs, page titles, visit timestamps, and visit counts. The temporary copy is deleted when the command finishes.

What it writes

Sentinel writes JSON and/or CSV history records and a verification report only to the output directory you choose. The report uses a profile label and database filename, not the absolute source path. These files are sensitive; protect or delete them as you would the original history.

This website

This static documentation site sets no cookies and uses no analytics, tracking pixels, third-party fonts, or third-party scripts. A service worker caches the public site files on your device for offline reading. Clear the site data in your browser to remove that cache.

Contact and changes

Questions and proposed changes can be filed in the public project repository. Material policy changes will be dated on this page. Because the software is local and anonymous, we cannot identify or retrieve your exports.
